This is the ClaimOps frontend/BFF built with [Next.js](https://nextjs.org), Better Auth, and Databricks-backed API routes.

## Getting Started

First, run the development server:

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Environment variables are defined in `.env.example`. For production deployment on GCP Cloud Run + Cloud SQL, use the root-level `cloudbuild.yaml` and [docs/deployment.md](/C:/Users/Krish/Desktop/projects/homeprojectabacus/docs/deployment.md).
